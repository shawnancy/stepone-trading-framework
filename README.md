## 这份材料在讲什么

可复用的不是某一笔多空，而是他反复出现的决策顺序：

1. 先问有没有优势（edge），再谈仓位。没有优势时，再严的风控也只是把亏损推后。
2. 先锁死生存约束：单笔风险上限和总回撤上限，再搭策略。
3. 凯利公式给出的是「每笔最多拿多少本金去冒险」，不是开几倍杠杆。杠杆要再用「每笔风险 ÷ 止损距离」换算（他按全仓说明）。他把公式结果当成仓位上限，而不是必须打满的目标。
4. 从「信号有效」到「账户盈利」中间隔着成本、执行、容量和衰减。回测要把成交假设往真实、苛刻的方向挪，不能拿触价当成交。
5. 公开逻辑会拥挤，策略多半是消耗品。真正能留下的，是可证伪的假设、样本外检验，以及出问题时先改自己的纪律。
